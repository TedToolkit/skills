# Review against learning

## Review against learning, not only liking

For a trial with representative novices, ask one question about the main outcome, one about a route or mechanism, and one application or prediction question. Record errors and confusion separately from enjoyment. Compare versions only with the same questions and a similar audience; a preference for a funnier version is not evidence of better learning. This is an evaluation plan, not a claim that the present draft has been experimentally validated.

For each teaching beat, record the intended inference, the relevant prior knowledge, the learner action (if any), the spoken cue, the visible state before and after, and the observable evidence or feedback. If one of these is absent, decide whether the beat is orientation, explanation, practice, or decoration before adding more narration or motion. This beat record is an authoring check, not mandatory learner-facing text or a claim established by one experiment.
